## Goal
- Convert all uint ID types to string UUID in controllers and service implementation files across the SimpleCommerce-Go project.

## Constraints & Preferences
- IDs are UUID v4 strings generated by PostgreSQL; controllers must NOT use `strconv.Atoi()` or `strconv.ParseUint()`.
- All `c.Locals("userID")` type assertions change from `.(uint)` to `.(string)`.
- All service method signatures change from `uint` to `string` for ID parameters.
- Pagination params (`page`, `pageSize`) stay as `int`.
- Write complete, compilable code, making minimum changes needed.
